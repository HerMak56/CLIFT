Abstract

A social robot has to keep track of the people around it over time to plan its motion — a task handled by 3D multi-object tracking. For the LiDAR modality, trackers usually sit on top of a detector and link its detections across frames with a separate motion model or re-identification network. We instead show how a 3D LiDAR detector itself can be turned into a tracker by adding an instance-level contrastive objective on its intermediate voxel features. Each embedding is read from the voxels inside a detected box, and boxes are matched across frames by cosine similarity and the Hungarian algorithm, without a motion model. The detector backbone is fine-tuned together with this objective under a gradient rule that keeps detection accuracy intact while learning identity-aware features. Because the method uses only the voxel features that LiDAR detectors already produce, it is backbone-agnostic.

Method in brief

  • Embeddings are pooled from the voxels inside each box, reusing features the detector already computes — no additional ReID encoder.
  • Association is cosine similarity plus Hungarian matching, with no motion model.
  • The backbone is fine-tuned jointly with the contrastive objective, so detection accuracy is preserved while the features become identity-aware.
  • Nothing in the approach is specific to one detector: it needs only intermediate voxel features, which LiDAR detectors produce anyway.
